# Project Rules

## Escopo
- Projeto: landing page de alta conversao para desafio feminino de saude.
- Stack: Next.js 14 App Router, TypeScript, Tailwind CSS, Framer Motion.
- Deploy: export estatico com trailingSlash.

## Prioridades
- Conversao do CTA para WhatsApp.
- Performance e Core Web Vitals.
- Conformidade LGPD para scripts de analytics.
- Visual moderno com glassmorphism e animacoes suaves.

## Restricoes
- Nao criar componentes fora da estrutura definida.
- Nao adicionar dependencias fora da lista aprovada.
- Nao executar scripts de analytics sem consentimento.
- Manter mobile-first como regra base.

## Workflow obrigatorio antes de implementacao
1. Ler `.ai/agent-memory.md`.
2. Carregar todos os skills em `.ai/skills`.
3. Validar a implementacao contra `.ai/project-rules.md`.
4. Validar a implementacao contra `.ai/coding-standards.md`.
5. Somente entao iniciar a implementacao.
