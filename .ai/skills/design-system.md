# Skill: Design System

## Responsabilidades
- Manter tokens de cores, tipografia, espacamento e glassmorphism.
- Garantir consistencia de gradientes, sombras e blur.
- Validar uso de animacoes conforme o sistema definido.
- Enforcar regras de layout mobile-first.

## Regras obrigatorias
- Usar tokens de `docs/DESIGN_SYSTEM.md` antes de criar novos valores.
- Padronizar componentes reutilizaveis para elementos repetidos.
- Manter hierarquia visual orientada a conversao.
- Seguir `.ai/project-rules.md` e `.ai/coding-standards.md`.

## Padroes de codigo
- Preferir classes utilitarias e variaveis CSS.
- Aplicar `.glass` e `.glass-light` como base de glassmorphism.
- Usar clamp para tipografia responsiva quando indicado.

## Anti-padroes proibidos
- Introduzir novas cores/fontes fora do design system.
- Ignorar touch targets minimos.
- Aplicar animacoes pesadas sem necessidade.

## Checklist de revisao
- Paleta e gradientes corretos.
- Tipografia conforme regras.
- Glassmorphism consistente.
- Espacamento e responsividade mobile-first.
